ParkSmart est une application Android destinée à digitaliser la gestion des entrées et sorties d'un parking. Elle permet de calculer les frais en temps réel, de capturer des photos de véhicules et de gérer les paiements. Le projet est développé avec Jetpack Compose pour l'interface et Supabase pour la base de données
captures d'ecran
Installation
1.
Dans Supabase, creez une table parking_sessions et un bucket vehicle_photos.
2.
Dans le fichier SupabaseClient.kt, remplacez les valeurs par votre URL et votre Cle.
3.
Lancez le projet dans Android Studio.
